# HOMYFLIX 🎬 + בוט וואטאפ

מערכת פשוטה להעלאת פוסטים (כמו קטלוג בנטפליקס), שבה כל פנייה של מתעניין
מגיעה אליך **אוטומטית לוואטאפ** דרך בוט.

## איך זה עובד?

1. אתה נכנס לעמוד הניהול ומעלה פוסט (כותרת, תיאור, מחיר, תמונה).
2. הפוסט מופיע בעמוד הציבורי (הקטלוג).
3. מבקר שמתעניין לוחץ **"מעוניין / צור קשר"** וממלא שם + טלפון + הודעה.
4. הבוט שולח לך מיד הודעת וואטאפ עם הליד — וגם נשמר בעמוד הניהול.
5. בנוסף: כל מי שכותב ישירות לבוט בוואטאפ מקבל מענה אוטומטי, וההודעה מועברת אליך.

החיבור לוואטאפ הוא **פשוט** — סורקים QR פעם אחת מהוואטאפ בנייד (כמו וואטאפ ווב),
בלי צורך בחשבון עסקי של Meta.

## דרישות

- [Node.js](https://nodejs.org/) גרסה 18 ומעלה.
- Google Chrome / Chromium מותקן (`whatsapp-web.js` משתמש בו ברקע).
- טלפון עם וואטאפ פעיל לסריקת ה-QR.

## התקנה

```bash
# 1. התקנת החבילות
npm install

# 2. הגדרת הסביבה
cp .env.example .env
# פתח את .env וערוך:
#   OWNER_NUMBER   = מספר הוואטאפ שלך (פורמט בינלאומי, ספרות בלבד. לישראל: 972501234567)
#   ADMIN_PASSWORD = סיסמה לעמוד הניהול (שנה אותה!)

# 3. הפעלה
npm start
```

## חיבור הבוט (פעם אחת)

1. הפעל `npm start`.
2. פתח בדפדפן: `http://localhost:3000/admin`
3. התחבר עם סיסמת הניהול.
4. בקטע "חיבור הבוט לוואטאפ" יופיע קוד QR.
5. בנייד: וואטאפ → **הגדרות → מכשירים מקושרים → קישור מכשיר** → סרוק את הקוד.
6. הסטטוס יהפוך ל-🟢 "מחובר". מעכשיו הסשן נשמר ואין צורך לסרוק שוב.

## כתובות

| כתובת | למה |
|-------|-----|
| `http://localhost:3000/` | הקטלוג הציבורי (משתפים עם לקוחות) |
| `http://localhost:3000/admin` | ניהול: העלאת פוסטים, QR, צפייה בלידים |

## טיפ: שיתוף החוצה

כדי שאנשים מבחוץ יראו את הקטלוג, אפשר לחשוף את הפורט עם כלי כמו
[ngrok](https://ngrok.com/):

```bash
ngrok http 3000
```

ולשתף את הקישור שמתקבל.

## מבנה הפרויקט

```
server.js          # שרת Express + ה-API + לוגיקת הבוט
src/whatsapp.js    # חיבור whatsapp-web.js (QR, סטטוס, שליחת הודעות)
src/store.js       # אחסון פוסטים ולידים בקובצי JSON
public/index.html  # הקטלוג הציבורי
public/admin.html  # עמוד הניהול
data/              # posts.json + leads.json (נוצרים אוטומטית)
```

## הערות

- אם `whatsapp-web.js` לא מוצא דפדפן, הוסף ל-`.env` שורה
  `PUPPETEER_EXECUTABLE_PATH=/path/to/chrome`.
- תיקיית `.wwebjs_auth/` מכילה את סשן הוואטאפ שלך — **לא להעלות ל-git** (כבר ב-`.gitignore`).
- האחסון מבוסס קבצים ומתאים לאב-טיפוס. לשימוש בקנה מידה גדול כדאי מסד נתונים.
